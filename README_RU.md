# ZakoOpt Forge 1.20.1 — рабочая область портирования

## ВАЖНО: это пока НЕ готовый порт оригинального мода

Этот ZIP создан на основе присланного `ZakoOpt-main.zip`. В нём есть:
- проект ForgeGradle для Minecraft 1.20.1 / Forge 47.x / Java 17;
- Forge entrypoint `zakoopt`;
- обязательная runtime-зависимость ImmediatelyFast в `mods.toml`;
- оригинальные исходники в `upstream-reference/` для переноса и сравнения;
- лицензии и NOTICE из оригинального репозитория.

**Оптимизации, миксины, меню настроек и остальная логика оригинала пока не подключены к Forge-проекту.**
Исходники в `upstream-reference/` намеренно не включены в компиляцию: они написаны для более новых версий Minecraft и содержат Fabric/NeoForge/Sodium-интеграции. Простое включение их в `src/main/java` не даст рабочую сборку 1.20.1.

Поэтому успешная сборка этого каркаса даст только минимальный Forge-мод-заготовку, а не функциональный ZakoOpt. Не устанавливай его вместо оригинального мода в ожидании прироста FPS.

## Сборка каркаса

Требуется JDK 17 и интернет для загрузки Gradle/ForgeGradle/Minecraft.

Windows:
```bat
gradlew.bat build
```

Linux/macOS:
```bash
./gradlew build
```

Выходной JAR:
`build/libs/zakoopt-2.1.3-forge1.20.1-port.jar`

## Проверка запуска

```bat
gradlew.bat runClient
```

В игровой instance нужно установить Forge 1.20.1 и совместимый Forge-вариант ImmediatelyFast. Метаданные проекта объявляют ImmediatelyFast обязательной зависимостью.

## Что ещё нужно сделать для настоящего порта

1. Заменить Fabric/NeoForge platform layer на Forge 1.20.1.
2. Перенести mixin-конфигурацию и проверить каждый injection point на Mojang mappings 1.20.1.
3. Переписать места, использующие API 1.21.x (рендеринг, буферы, HUD, частицы, сущности и блок-сущности).
4. Удалить/адаптировать интеграции Sodium; пользовательская целевая сборка не использует Sodium или Embeddium.
5. Перенести экран настроек, регистрацию клавиш и загрузку конфигурации.
6. Проверить зависимости Create и других модов, для которых существуют отдельные оптимизации.
7. Собрать и проверить в игре, затем включать функции по одной.
